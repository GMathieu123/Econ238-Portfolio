# Week Eleven — Hire the Beavers

**What if we paid wildlife to create flood protections?**

This is my ECON 238 Week Eleven Batsh!t environmental economics proposal.

**[View the one-page infographic and complete project](./index.html)**

**[Read the full written project and references](./full-project.md)**

The proposal explores a Beaver Payroll: landowners would be compensated for maintaining suitable beaver wetlands, with payments connected to measured environmental and flood-risk benefits. The costs, flood-risk reductions, and financial scenarios in this project are hypothetical estimates, not demonstrated outcomes.
